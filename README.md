# Lista de Contactos

Aplicacion frontend hecha con HTML, CSS y JavaScript Vanilla para practicar manejo del DOM y localStorage.

## Funcionalidades
- Crear contactos
- Leer contactos guardados en pantalla
- Actualizar contactos desde la lista
- Eliminar contactos individuales o todos
- Validar campos vacios
- Identificar genero con iconos claros
- Mostrar spinner de carga y mensajes de confirmacion

## Tecnologias
- HTML
- CSS
- JavaScript Vanilla
- localStorage

## Uso
1. Abre `index.html` en el navegador.
2. Agrega un contacto con el formulario.
3. Edita o elimina desde los botones de accion.
4. Recarga la pagina para verificar que los datos sigan guardados.
